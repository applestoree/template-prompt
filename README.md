# Visual Prompt Template

Template dasar untuk menyusun prompt visual produk Apple secara terstruktur.

## Prompt Variables

```text
[subject]:

[action]:

[background]:

[composition]:

[layout]:

[visual]:

[lighting]:

[typography]:

[quality]:

[ratio]:
```

## Variable Guide

| Variable | Fungsi |
|---|---|
| `[subject]` | **Wajib menampilkan produk Apple sebagai subjek utama.** Sebutkan nama produk dan model secara spesifik, misalnya iPhone, iPad, Mac, Apple Watch, atau AirPods. Pertahankan identitas desain, bentuk, warna, material, dan detail produk sesuai model yang disebutkan. Jangan mengganti produk dengan perangkat generik atau merek lain. |
| `[action]` | Menentukan aktivitas, posisi, atau interaksi produk Apple dengan lingkungan atau elemen pendukung. |
| `[background]` | Menentukan latar tempat, lingkungan, dan elemen pendukung. |
| `[composition]` | Mengatur framing, sudut pandang, perspektif, dan penempatan produk. |
| `[layout]` | Mengatur susunan elemen visual dan ruang kosong dalam desain. |
| `[visual]` | Menentukan arah seni, gaya visual, dan karakter tampilan. |
| `[lighting]` | Menentukan sumber, arah, intensitas, dan karakter pencahayaan. |
| `[typography]` | Mengatur teks, hierarki tipografi, dan penempatannya; gunakan bila diperlukan. |
| `[quality]` | Menentukan detail, ketajaman, kualitas render, dan standar hasil akhir. |
| `[ratio]` | Menentukan rasio aspek atau format keluaran gambar. |

## Subject Rules

- Subjek utama harus berupa produk Apple.
- Gunakan nama produk dan model yang spesifik jika informasinya tersedia.
- Produk Apple harus menjadi fokus visual utama dan mudah dikenali.
- Jaga akurasi desain produk; jangan menambahkan fitur, bentuk, kamera, port, tombol, atau detail yang tidak sesuai dengan model.
- Jangan menampilkan logo atau identitas merek lain sebagai pengganti Apple.

## Usage

1. Isi setiap variable sesuai kebutuhan konten.
2. Pastikan `[subject]` menyebutkan produk Apple yang akan ditampilkan.
3. Pertahankan nama variable agar konsisten saat digunakan oleh Prompt Engine.
4. Hapus atau kosongkan variable yang tidak relevan untuk kebutuhan tertentu.
5. Gabungkan seluruh instruksi menjadi satu prompt final sebelum dikirim ke Image Generator.
