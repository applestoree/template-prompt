# Visual Prompt Template

Template dasar untuk menyusun prompt visual secara terstruktur.

## Prompt Variables

```text
[subject]:

[action]:

[background]:

[composition]:

[layout]:

[visual]:

[lighting]:

[typography]:

[quality]:

[ratio]:
```

## Variable Guide

| Variable | Fungsi |
|---|---|
| `[subject]` | Menentukan objek, produk, atau subjek utama yang ditampilkan. |
| `[action]` | Menentukan aktivitas, pose, atau interaksi subjek. |
| `[background]` | Menentukan latar tempat, lingkungan, dan elemen pendukung. |
| `[composition]` | Mengatur framing, sudut pandang, perspektif, dan penempatan subjek. |
| `[layout]` | Mengatur susunan elemen visual dan ruang kosong dalam desain. |
| `[visual]` | Menentukan arah seni, gaya visual, dan karakter tampilan. |
| `[lighting]` | Menentukan sumber, arah, intensitas, dan karakter pencahayaan. |
| `[typography]` | Mengatur teks, hierarki tipografi, dan penempatannya; gunakan bila diperlukan. |
| `[quality]` | Menentukan detail, ketajaman, kualitas render, dan standar hasil akhir. |
| `[ratio]` | Menentukan rasio aspek atau format keluaran gambar. |

## Usage

1. Isi setiap variable sesuai kebutuhan konten.
2. Pertahankan nama variable agar konsisten saat digunakan oleh Prompt Engine.
3. Hapus atau kosongkan variable yang tidak relevan untuk kebutuhan tertentu.
4. Gabungkan seluruh instruksi menjadi satu prompt final sebelum dikirim ke Image Generator.
